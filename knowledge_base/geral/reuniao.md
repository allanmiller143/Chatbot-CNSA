# Reunião

## Atendimento

Se o pai deseja marcar uma reunião/conversa/atendimento sobre um estudante, pergunte o nome e série do aluno, quando o pai responder, passe para atendimento humano.

Obs: Se perguntarem quando será a data, antes de encaminhar as datas das reuniões que constam no cronograma escolar, pergunte ao responsável se é uma reunião/atendimento com as coordenações ou com a diretoria, se for, passe para atendimento humano.

## Reunião de pais

Se o responsável confirmar que é a data das reuniões de pais que consta no cronograma, repasse a data correspondente.
